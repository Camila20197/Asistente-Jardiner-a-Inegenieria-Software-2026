# Procedimiento — Entrega y criterios generales de evaluación

**Aplica a:** TP1 a TP5 y Trabajo Integrador

## Antes de cada presentación

- [ ] Todo el material está commiteado en el repositorio del grupo — nada en documentos externos.
- [ ] Los diagramas están en bloques ` ```mermaid ` dentro de `.md`, no como imágenes.
- [ ] `docs/uso-ia.md` está actualizado con la entrada correspondiente a este TP.
- [ ] Existe una línea base etiquetada (`git tag`) para esta instancia.
- [ ] Todos los integrantes pueden defender cualquier decisión del documento, no solo la parte que escribieron.

## Qué se evalúa en toda instancia (dimensiones generales)

1. **Calidad técnica** de los artefactos entregados (corrección, completitud, precisión).
2. **Comprensión real del dominio**, no aplicación mecánica de una plantilla genérica.
3. **Argumentación oral**: por qué esta decisión y no otra, qué alternativas se descartaron.
4. **Reflexión sobre uso de IA** — ver `docs/procedimientos/uso-de-ia.md`.
5. **El repositorio Git como evidencia del proceso**: historial de commits, no solo el resultado final.

Las dimensiones puntuales de cada instancia (qué artefactos, qué preguntas guía) están en la guía del TP correspondiente, en `docs/tp/`.
